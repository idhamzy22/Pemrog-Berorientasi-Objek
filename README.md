# ☕ **Laporan Sistem Manajemen Cafe**  

## 🔹 **A. Cafe Shop Management System**  
### 🔍 **Nama Proyek:** 
Sistem Manajemen Cafe dengan Java NetBeans  

---

## 🏁 **B. Pendahuluan**  
### 📌 **1. Latar Belakang**  
Cafe Shop merupakan sebuah cafe yang menawarkan berbagai makanan dan minuman serta tempat yang nyaman untuk berkumpul. Untuk meningkatkan efisiensi operasional dan layanan pelanggan, dibutuhkan sistem manajemen yang memungkinkan pengelolaan produk, transaksi, dan laporan secara efektif. Oleh karena itu, sistem ini dikembangkan menggunakan **Java** dengan platform **NetBeans** serta alat bantu lainnya.  

### 🎯 **2. Tujuan**  
✅ Mengembangkan sistem yang dapat mempermudah administrasi cafe  
✅ Meningkatkan akurasi dan kecepatan dalam pemrosesan transaksi  
✅ Menyediakan laporan yang informatif untuk pengambilan keputusan  
✅ Memastikan keamanan data pengguna melalui sistem login untuk admin  

---

## 🔹 **C. Metodologi**  
### 🛠 **1. Alat dan Bahan**  
- **Bahasa Pemrograman:** Java  
- **IDE:** NetBeans  
- **Database:** MySQL  
- **Framework:**  
  - JDBC → untuk koneksi database  
  - FXML → untuk desain antarmuka pengguna berbasis JavaFX  
  - Jasper Reports → untuk menghasilkan laporan profesional dan dinamis  
  - Scene Builder → alat untuk mendesain antarmuka pengguna secara visual menggunakan FXML  

### 📌 **2. Langkah Pengembangan**  
1️⃣ **Analisis Kebutuhan Pengguna** → Mengumpulkan informasi mengenai kebutuhan sistem dari pengguna potensial.  
2️⃣ **Desain Sistem** → Membuat flowchart dan wireframe menggunakan **FXML & Scene Builder**.  
3️⃣ **Pengembangan** → Implementasi fitur menggunakan **Java**, koneksi database dengan **JDBC**, serta pembuatan laporan menggunakan **Jasper Reports**.  
4️⃣ **Pengujian** → Menguji fungsionalitas login admin, pengelolaan produk, transaksi, dan laporan.  
5️⃣ **Implementasi & Pelatihan** → Mengadakan pelatihan bagi staf cafe dalam penggunaan sistem.  

---

## 🔹 **D. Deskripsi Sistem**  
### 🚀 **1. Fitur Utama**  
#### 🔑 **a. Sistem Login**  
- **Login Admin:**  
  ✅ Admin dapat masuk ke dalam sistem menggunakan username & password  
  ✅ Keamanan ditingkatkan dengan hashing password & sesi manajemen  

#### 🍽️ **b. Manajemen Produk**  
- **CRUD (Create, Read, Update, Delete):**  
  ✅ Menambahkan produk baru (makanan/minuman)  
  ✅ Mengedit informasi produk  
  ✅ Menghapus produk yang tidak tersedia  
  ✅ Menampilkan daftar produk dengan fitur pencarian dan filter berdasarkan kategori  

#### 💳 **c. Transaksi Penjualan**  
- **Pemrosesan Pemesanan:**  
  ✅ Membuat pesanan baru  
  ✅ Menghitung total biaya  
  ✅ Memproses pembayaran (tunai/kartu)  
  ✅ Menyediakan **struk transaksi** menggunakan **Jasper Reports**  

#### 📊 **d. Laporan Keuangan**  
- **Pembuatan Laporan:**  
  ✅ Laporan **penjualan harian, mingguan, dan bulanan**  
  ✅ **Analisis menu terlaris**  
  ✅ Grafik & statistik untuk pemantauan kinerja cafe
